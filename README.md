# TileGB

TileGB is a web-based tool for converting images into Game Boy-compatible 8x8 tiles with deduplication and export features.
It is designed to integrate easily into workflows using Game Boy Tile Designer.

## Features (planned)
- Image import
- Tile slicing (8x8)
- Tile deduplication
- Export for Game Boy Tile Designer
- Map / layout editor
