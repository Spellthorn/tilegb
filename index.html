How to Use TileGB

TileGB is designed to work alongside Gameboy Tile Designer and helps prepare images for easy import.

Preparing Images

Before uploading an image, make sure it uses no more than four colors. These should be the standard Game Boy grayscale colors:

  • 0 - #FFFFFF
  • 1 - #C0C0C0
  • 2 - #808080
  • 3 - #000000

Using different shades may cause unexpected results when importing into Gameboy Tile Designer.

Managing Images

  • Click an image to select it.
  • Hold CTRL and click an image to delete it.

Duplicate Tile Removal

TileGB automatically removes duplicate tiles.

For sprite sheets, you can enable Remove Flipped Sprites. This removes tiles that can be recreated by flipping another tile horizontally or vertically.

Do not use this option for backgrounds, maps, or tile screens.

Exporting to Gameboy Tile Designer

Once your images are configured, click Copy Image.

In Gameboy Tile Designer, select:

Edit → Split Paste

This will import the generated tile data directly into the designer.

Troubleshooting

If your tiles look incorrect after importing, verify that your source image uses only the four Game Boy colors listed above.
